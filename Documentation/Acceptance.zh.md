## 试玩记录模板

- 日期、构建版本、commit、测试者代号（不需要私密身份信息）：
- 是否首次接触、此前相关游戏经验：
- 练习区是否能无口头帮助完成：
- 三单用时，读卡用时，失败/重试数：
- 每项能力是否被识别、独立运用、迁移到新用途：
- 可观察问题与玩家原话（如有）：
- 替代解释，例如操作生疏、镜头或标记问题：
- 决定修改什么、为什么；对应 commit：
- 复测结果：

不得把开发者自测、自动化检查或计划中的改动写成真实玩家反馈。

## 各版本最低检查

- [ ] 首次启动，开场卡能读完、返回；倒计时未提前启动。
- [ ] 鼠标/键盘输入不会穿透故事卡或暂停菜单。
- [ ] 提示对应真实按键与规则；帮助可重新打开。
- [ ] 慢动作只影响指定对象；玩家/计时/冷却行为一致。
- [ ] 移动平台减速与恢复不弹飞角色。
- [ ] 掉落、碰撞、超时、手动重试均不会软锁。
- [ ] 本单重试重置全部本单状态，之前交付保留。
- [ ] 三次送达均有反馈，最终结局可达。
- [ ] 无调试文字、无缺失资源、无未授权素材。
- [ ] 文档中的数值、模式、规则与最终构建一致。
