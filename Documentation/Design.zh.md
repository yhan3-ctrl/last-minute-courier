# 《最后一刻快递员》制作规格 v0.1

状态：实施基线。以下数值为初始设计假设，尚未经过试玩，不可写成测试结果。

## 游戏承诺与范围

玩家是一名校园快递员，在电影夜开场前送达三份急件。通过跑动、跳跃和短时慢动作，穿过移动障碍并选择捷径。轻松、有节奏、能快速重试。第三人称 3D，Unreal Engine，键鼠优先。

一个紧凑校园关卡，按三个订单依次开放相连区域。前一订单的交付点就是下一订单领取点，避免空跑返回仓库。目标首次完整游玩 5–10 分钟，其中实际挑战约 5–7 分钟；不靠读卡、强制等待或重复失败凑时长。

首版不加入战斗、驾驶、开放世界、物理包裹搬运、复杂人群 AI、随机任务或时间倒流。包裹领取后作为角色背包外观与任务状态存在，避免物理卡住。

## 故事线

今晚学校在钟楼广场举办露天电影夜。布场临近结束，但三个地点还缺急件：咖啡摊的保温箱、投影台的镜头盒、钟楼控制台的开场胶片。你接下最后一轮配送。

实验室借给你一枚“借秒器”。它通过校园运输装置的蓝色时间标签，让运输车和升降台暂时减速；你的步伐和订单倒计时照常进行。这样既交代能力边界，也避免“为什么开了慢动作倒计时不慢”的矛盾。

每次交付都改变广场：咖啡摊亮灯、投影光束出现，最后胶片送达、银幕亮起。结尾是“放映开始。你也有一个座位。”角色把空背包放下，画面落在自己的空椅子与银幕上。用简单镜头和环境变化完成，不依赖角色表演或长过场。

语气：温暖、轻快，紧张来自配送节奏。失败提示不羞辱玩家，不宣称所有人因玩家失败而失望。

## 语言：用户已确认

每次新运行默认英文，不根据系统语言自动切换。开场与暂停菜单均提供 Language 下拉选项，供玩家自由选择 English、简体中文、日本語、한국어、Español、Français、Deutsch；L 依次切换。主要菜单、开场故事、教程与 HUD 共用 `DesignData/localization.json`。新增玩家文字必须补齐所有已支持语言，并复查字形与排版；校园世界中的英文店招目前保留场景原文。

## 开场引导卡：用户明确要求

背景显示实际校园场景；卡片固定镜头下阅读，游戏计时与障碍暂停。三张卡每张只表达一件事，点击或 Enter 继续，Back 返回。最后一张按钮为“进入练习区”。无自动翻页、无阅读倒计时、无首次强制跳过按钮。暂停菜单提供“重新查看故事与操作”。之后可从标题画面选择重新看故事或直接进入练习。

1. **今晚，电影夜**：“钟楼广场马上开场。咖啡、镜头和胶片还在路上。你是今晚最后一位快递员。” 配图由远处银幕、布场灯与快递柜体现。
2. **借来的三秒**：“实验室借给你一枚借秒器。按住 Q，让带蓝色时间标签的装置减速；你照常行动。订单倒计时不会变慢。” 展示一个车和一个平台的蓝色标签。
3. **三份急件，一个晚上**：“沿着包裹与目的地标记前进。送达后在同一地点领取下一单。出错可以重试当前订单。” 按钮“进入练习区”。

阅读后才进入可操作的无倒计时练习区。分步提示移动、跳跃、慢动作；一次只显示当前所需提示，用实际成功行为解锁下一条。不要在故事卡同时塞满按键。

## 操作与规则

| 操作 | 默认输入 | 规则 |
|---|---|---|
| 移动/视角 | WASD / 鼠标 | 默认奔跑，无额外体力系统；输入提示支持键盘布局复核 |
| 跳跃 | Space | 固定可理解的跳跃能力；首版无二段跳 |
| 借秒器 | 按住 Q | 所有激活的蓝色标签动态对象以 25% 速度运行；最长连续 3 秒，松开立即恢复 |
| 再充能 | 自动 | 每次结束后冷却 4 秒，期间不能重开；完整充能后才能再次使用 |
| 接单/交付 | E | 仅在明确高亮的交互区域内生效；领取前显示订单信息，确认后才启动倒计时 |
| 暂停/帮助 | Esc | 暂停世界、订单和冷却；可继续、查看帮助、重试当前订单或回标题 |

慢动作不改变玩家、镜头、订单计时、冷却和 UI 的速度。用单独可减速对象的时间倍率实现，不使用全局时间缩放。移动平台需要正确承载玩家，激活/结束慢动作时不应弹飞玩家。

碰到运输车会短暂受阻并后退到安全位置，无生命值、无包裹破损。接触后约 1 秒保护，避免持续碰撞锁死。掉落到水面或地图外，恢复到本单最近检查点，约 0.5 秒淡入淡出；恢复过程中暂停订单计时，不额外扣秒。若剩余时间已不足，玩家可主动重试本单。

超时显示“差一点，再送一次”，提供“重试这一单”和“查看路线提示”。无强制惩罚等待。本单重试重置玩家、包裹、障碍相位、平台、检查点、慢动作与倒计时；先前完成订单和环境反馈保留。首版仅在本次运行内保存进度，退出程序后重新开始，须在帮助中说明。

目的地用名称、图标和距离共同表达；色彩不是唯一线索。近处有地面方向标记，远处显示目的地标牌；遮挡时保留屏幕边缘箭头，避免玩家穿墙直走。到点后仍需 E，防止经过就误触交付。正在显示引导或结果卡时不能重复接单。

## 关卡流程和机制迁移

起点：快递站旁安全小院，学习移动与转向；跨过低矮台阶学跳跃；看见蓝色运输车，按住 Q 通过，学会慢动作。提示通过实际动作完成，无计时压力。

| 订单 | 剧情/路线 | 玩家决策与新用途 | 初始预算 |
|---|---|---|---|
| 1：把暖意送到 | 快递站→咖啡摊；广场边的两段运输车道和低台阶 | 从无压力演示迁移到间隔不同的车道；可等待间隙，也可使用慢动作，不能强迫无意义等待 | 首次目标 80–110 秒；倒计时 140 秒 |
| 2：让银幕亮起来 | 咖啡摊领取镜头盒→投影台；花园与服务坡道 | 跳上升降台后，利用慢动作延长平台处于合适高度的窗口，从“躲危险”转为“创造可通行时机”；宽阔普通路作为较长替代 | 首次目标 100–140 秒；倒计时 170 秒 |
| 3：最后一卷 | 投影台领取胶片→钟楼控制台；街巷和钟楼露台 | 先用慢动作穿车道，再在冷却期间选择普通路或等待机会登平台；路线选择、跳跃和减速时机组合。不能要求在冷却期间再次施放 | 首次目标 120–170 秒；倒计时 200 秒 |

布局是地标清晰、路径逐段向前的校园。第一单约 8–10 次短操作节奏，第二、三单每段加入有意义的不同挑战。实际关卡长度、时长和难度需要首次试玩修正；如果过短，增加不同用途的挑战，不用拖慢移速或添加空走来补时。

每项能力的后续新用途：移动从遵循标记前进转为选择绕行/捷径；跳跃从固定低障碍转为判断移动平台的起跳时机；慢动作从避让车流转为延长登台窗口，再用于安排连贯路线。制作中必须对每一项逐一验证。

## UI 状态与反馈

标题→故事卡→安全练习→待接单→配送→交付结果→下一单待接单→最终结局。暂停和帮助为可返回的覆盖层；超时进入本单重试页面；掉落恢复回配送。文档用这份状态清单描述实际体验，课堂 Game Modes 术语待第 3 套课件核实。

HUD 只显示订单名称/3、目的地、剩余时间和慢动作能量。接近交互点才显示 E。最后 20 秒使用轻提示，不闪烁全屏红光或持续刺耳警报。

慢动作开始：蓝色标签变为双环、物体运动显著放慢、简短音效；无强制视野抖动、无运动模糊。能量条与“就绪/冷却”文字同步。结束前用条形进度提示，不靠颜色单独传达状态。

交付后包裹贴上一枚邮戳；三枚邮戳在结局组成电影票。结算显示三单完成、配送用时、重试次数，可重玩。首版不做排行榜和复杂评级，避免玩家因熟练度低看不到完整结尾。

小巧思按优先级：
1. 三次交付逐步点亮同一片广场，让玩家看见自己的贡献。
2. 包裹标签分别写“趁热”“轻放”“全场都在等这一卷”，以一句话塑造订单个性。
3. 关键路口有静态校园告示：“请勿用借秒器延长考试。”作为主题笑点，不增加系统。
4. 最终电影票留给快递员自己，呼应开头的忙碌。
5. 只有核心流程稳定后，才加纸屑、包裹轻微晃动和环境音等装饰。

## 美术、音频和性能

干净的低多边形校园，暖橙色黄昏、奶油色建筑、蓝色时间标签、金色目的地。先用原生几何体搭建并统一比例与材质；适用时用合法可分发的模板角色/动画。先保证摄像机不穿墙、路径可读、帧率稳定，再增加装饰。音频需合法来源且记录许可；音效可选，所有关键反馈都有视觉对应。

M4 / 16 GB Mac 为首个开发测试环境；关闭不必要的高成本渲染特性，初版不依赖高端图形功能。具体设置等引擎可运行后测量决定。

## 制作顺序

1. 环境：启动器、兼容 UE 与 Xcode、最小工程启动；核实存储空间，尽早安排跨平台构建。
2. 一段可玩流程：第三人称移动、开场卡、安全练习、包裹交互、一辆车、慢动作、一次交付和本单重试。
3. 完成订单一，进行真实试玩并记录反馈，调整可读性、操作和计时。
4. 增加平台、订单二与第三单组合关卡，再试玩并验证机制迁移和实际时长。
5. 完成环境变化、结尾、帮助、声音与视觉细节；补齐文档，核对实现。
6. 三平台打包、独立启动测试、GitHub/Box/Blackboard 提交材料。

任何阶段失败都先修流程，不继续堆功能。开场卡、暂停、失败、重试和结尾属于必须完成的体验，不能留到最后。
