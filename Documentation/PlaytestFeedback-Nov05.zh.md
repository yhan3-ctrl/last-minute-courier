# 2026-11-05 练习区真实试玩反馈

版本：用户试玩 v0.5.2；回应版本 v0.5.3。测试者：项目所有者、研究生。范围：正在进行的 practice，非完整通关；没有总时长、舒适度或听感结论。

## 原话与证据范围

- 用户：“为什么我们通过快递蓝色车的时候要按住Q……人们第一反应想的是趁那个车走向另外一边的时候我们快速通过……每次我这样快速通过之后都会重生。”
- 用户：“还有那个路线不明显，可以明显一些。”

这些是用户报告的体验，不能推断每次重生都来自同一原因。代码核查确认旧版在 x1900 后会因未完成持续 Q 检查而恢复检查点，即使已经安全离开车道；真正撞车还有独立的碰撞检测。

## 改动与复核

v0.5.3 删除强制 Q 的教学重生检查。安全通过即可推进并保存前方检查点；Q 用于延长空隙。实际撞车仍恢复检查点，文案明确说明撞车原因。持续橙色引导线、每五米左右的大箭头、下一目标圆环和悬浮指针替代细小稀疏标记；只显示当前任务的路线，岔路仍保留可走的替代路线，所有引导物无碰撞。

Nov05-LogicalCrossing 的三个引擎回归组通过，测试错误/警告均为零，覆盖不按 Q、提前松开 Q、使用 Q、安全空隙和真实撞车，以及引导分组/碰撞。普通键盘技术试玩没有按 Q，通过车道后显示 Safe crossing 和下一步说明，能量仍为 3.0 秒。画面检查观察到连续箭头、清晰的目标圆环和较大的方向面板。随后工具报告用户正在操作窗口，停止继续发键，把窗口留给用户。

待补：用户对 v0.5.3 的复测反馈、完整通关时长、后续平台上独立使用 Q、镜头舒适度和音乐体验。不能把这次部分反馈写成完整真人通关或 5–10 分钟已达标。
