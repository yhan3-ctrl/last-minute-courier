# 第一单原型：已编译运行，视觉与舒适度初版

## 当前范围

原生 Unreal C++ 工程，使用引擎内置几何体。源码包含：

- 三张开场故事卡；每次新运行默认英文。Enter 继续，Backspace 返回。开场与暂停菜单提供 Language 下拉选择：英文、简体中文、日文、韩文、西班牙文、法文、德文；L 为依次切换快捷键。
- 第三人称移动、鼠标视角、空格跳跃；C 镜头回正，也可在暂停菜单按按钮。
- 无倒计时练习区，按位置和操作进展逐条显示提示。
- 按住 Q 减慢蓝色运输车，最长 3 秒，结束后冷却 4 秒。
- E 领取第一单后开始 140 秒倒计时，到咖啡摊按 E 交付。
- 途中检查点，碰撞/越界恢复；R 重试本单，Esc 暂停，H 查看故事与操作。
- 送达后咖啡摊点亮，并显示第一单原型完成。
- 校园场景初版：校舍、树木、长椅、取件亭、咖啡摊与钟楼；自有哑光材质和浅色天空。
- 原生 Slate UI，Bree Serif / Atkinson Hyperlegible / Noto Sans CJK SC 字体；镜头灵敏度、FOV 与可选方向锁定。

UE 5.8.4 / Xcode 27.1 下 Editor 目标已编译成功，初始地图与材质已通过 Unreal Python commandlet 生成。代理已在带图形界面的游戏中检查英文默认开场、中文切换与字形、故事卡翻页、移动/跳跃教学、Q 后充能、E 接单与计时开始、第一单成功交付、R 回到取件点、暂停/恢复、设置滑条键盘调整、镜头锁定勾选及校园渲染。途中触发了检查点恢复后仍可完成交付；2026-10-29 新增引擎回归验证了超时、暂停冻结、暂停期间松开 Q、充能、检查点和重试；受控位置与显式计时测试不代表完整真人操作验证。第一条直线路线用于检验流程和输入，不是最终关卡，也不能用来证明 5–10 分钟要求。

## 工程文件

`LastMinuteCourier.uproject` 现绑定已安装的 UE 5.8。依据首次构建工具输出，源码目标更新为 BuildSettingsVersion.V7 和 Unreal5_8 包含顺序；这避免项目覆盖与预编译编辑器共享的构建设置。

工程中已有 `Content/Maps/L_Courier.umap`，由 `Scripts/bootstrap_map.py` 创建并保存。该脚本遇到已有地图时保留它，不覆盖内容。

可以在 Terminal 用 `Scripts/build_editor.command /引擎安装根目录` 调用原生 Unreal 构建工具；编译日志与我们指定的派生缓存写入本项目。不能在缺少完整 Xcode 或不兼容版本的情况下宣称构建完成。

用户要求只操作 `game development` 文件夹。新工程、素材、构建和主动生成的缓存都应留在本 Project3 中。
