# v0.4：三单连贯原型

## 已实现

- 四张开场卡分别解释电影夜故事、借秒器、三单目标与接单规则、完整操作。每次新启动默认英文，可选简中、日、韩、西、法、德；暂停菜单可再次选择。
- 无倒计时练习区：移动、实际跳跃、靠近蓝标车使用 Q。走过路口或远处按 Q 不能跳过教学。
- 咖啡→咖啡摊；镜头→投影台；胶片→钟楼。每单先按 E 阅读简报，再按 Enter 接受，阅读时不计时。倒计时分别 60/150/160 秒（v0.5.4 收紧；原 140/170/200 秒时自动试玩每单都剩一半以上），不能据此声称实际游玩时长。
- 送达后原地进入下一单，无需空跑回原取件点。三单送达逐步点亮咖啡摊、投影台和电影夜；最终电影票显示三个印章及配送成绩。
- 花园升降台、真实有间隙的踏石、横移接驳台、上层花架；每段有坡道或侧道选择。Q 最长 3 秒减慢蓝标装置至 0.25 倍，充能 4 秒；玩家和订单时钟保持正常速度。
- 方向文字和距离、按 H 打开路线提示、按 C 朝当前路线目标回正。侧道上的导航沿侧道继续，避免指向水面捷径。
- 碰撞和掉落恢复到安全检查点，0.3 秒淡入并暂缓移动/设备/时钟。重试只清空未完成的当前单，之前印章保留；暂停冻结时钟、装置和能力状态。
- 原生 Slate 排版；Bree Serif、Atkinson Hyperlegible 和分区 Noto CJK 字体。视野、灵敏度和镜头方向锁定可调，无头部晃动、镜头震动、动态 FOV 或运动模糊。
- 自制黄昏渐变、暖阳、云层和远景；材质支持实例化草地；无体积云/体积雾。
- 48 秒自制电钢琴/木质拨音循环，轻柔节奏；简报、取件、借秒、盖章、结局和脚步共六类音效。暂停菜单可关闭全部声音。

## 验证范围与限制

Editor 目标已在此 Mac 编译成功。引擎自动化覆盖第一单状态边界、三单连贯流程与真实引擎帧中的移动平台搭乘；最终 FinalJourneyV04 为三组成功、0 测试错误/警告，包括六处坡道胶囊通行检查。详见 QA-Evidence.json。受控坐标和模拟时间不代替完整玩家操作。源语言覆盖检查通过，六种可选语言仍需母语审阅。鼠标点击自动化受 noWindowsAvailable 工具错误影响，不能以此断言游戏按钮坏了。

仍需完整首次玩家测试、5–10 分钟实际时长与镜头舒适度测量、低帧率和各平台独立发行版验证。未完成 Windows/Linux/Mac 打包，未上传提交。课堂文档格式和研究生附加项仍待核对。

## 工程运行

Scripts/build_editor.command 编译，play_prototype.command 预览，audit_game.command 运行三组 Courier.Regression 测试。均为进程单独选择 Xcode，不改全局开发工具设置。重建材质和导入自制声音使用 build_presentation_assets.command。

主实现：CourierPrototype.cpp（角色、输入、状态）、CourierJourney.cpp（订单、导航、声音）、CourierWorld.cpp（园区与装置）、CourierUI.cpp（界面）；DesignData/game_content.json 提供故事卡和订单文案，localization.json 提供其他语言。部分数值仍为源码常量，修改时需同步文档及配置。

生成缓存位于 Project3/Runtime.nosync，源码/素材仍在项目原位置。文件操作边界为 Project3，必要软件运行数据已获用户例外授权。

实机复查：默认英文、四卡翻页、英/中/德操作卡布局、练习区、第一单侧道与交付、无计时简报、声音勾选开关和掉落恢复已用代理键盘操作检查。护栏修复后从受控起点实际走过花园转角及连接处；结局从开发用 Cinema 起点检查，屏幕中的用时不代表完整游玩。截图见 Previews；尚无完整三单真人输入与计时验收。
