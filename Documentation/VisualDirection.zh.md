# 视觉与镜头方向

## 目标

校园电影夜的轻松配送：暖色校舍、奶油色纸张、砖橙色行动按钮、蓝绿色配送设施。3D 与 UI 使用同一套颜色和语气。先让人看懂路线、装置和目的地，再增加装饰。

参考 [A Short Hike](https://ashorthike.com/) 的简洁场景层次，以及 [Alba](https://ustwogames.co.uk/our-games/alba-a-wildlife-adventure/) 的自然配色与场景辨识度。这是方向参考；没有复制其资产，也没有声称知道其具体字体。

## 已落实到第一单预览

- 第三人称角色；宽阔平坦道路；远处钟楼作为方向地标。
- 取件亭、咖啡摊、树木、长椅、窗户与屋顶组成初步校园场景；侧面装饰离开主要镜头通道。
- 橙色稀疏地面指引；蓝色运输车同时带有时钟图案，识别不只依赖颜色。
- 项目自有哑光材质与浅色天空；不依赖大型付费美术包、Lumen 或高分辨率纹理。
- Slate 原生故事卡、暂停菜单和 HUD。拉丁字母标题使用 Bree Serif，正文使用 Atkinson Hyperlegible；中、日、韩文分别使用 Noto Sans CJK SC / JP / KR。授权见 ASSET_CREDITS.md。
- 每次启动默认英文；开场与暂停菜单提供 Language 下拉选项，支持英语、简体中文、日语、韩语、西班牙语、法语、德语。L 可依次切换。故事卡、教程、HUD 与暂停菜单共用翻译表。

## 镜头与舒适度

- 默认水平 FOV 90°，暂停菜单可调 80–100°。
- 鼠标灵敏度可调，默认 0.6；限制单帧累计转角造成的突然跳转。
- 没有走路晃动、震屏、镜头滚转、速度变焦或运动模糊；没有自动转向目的地。
- 可选“锁定镜头方向”：固定当前朝向，继续用 WASD 行走；恢复自由观察时取消勾选。
- 镜头俯仰范围 -60° 至 20°；不自动切换镜位。
- 恢复检查点时保持朝向，以 0.3 秒黑色淡入遮蔽位置跳变。
- 设置支持 Tab 选择，空格切换镜头锁定，Enter 启用滑条后用左右方向键调整，Esc 返回游戏。

设计参考 [Xbox Accessibility Guideline 117](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117) 对视野、灵敏度及镜头运动设置的建议。以上实现不能保证每位玩家都不晕；需要真实玩家的舒适度反馈。

## 仍需打磨与验证

v0.4 已有花园、平台路线和电影广场，三单形成不同空间；已加入角色步行动画、自制音频、目的地与侧路指引，整体节奏仍待首次玩家测试。当前检查只证明开发机上能运行，尚无稳定帧率数据、低配测试或人类舒适度结论。

试玩时记录：是否需要频繁大幅转镜头、是否看得清下一步、转弯/跳跃/恢复检查点是否难受、文字是否遮挡障碍、默认灵敏度是否过快。保留不适或找不到路的反例，不能只记录喜欢的反馈。
